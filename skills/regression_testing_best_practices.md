# Regression Testing Best Practices

## Description
This skill outlines best practices for conducting regression testing to ensure that new changes do not introduce new bugs into the system.

## How to Apply
1. Maintain a comprehensive suite of regression tests that cover critical functionality.
2. Run regression tests after every significant code change or addition.
3. Analyze test results to identify any regressions and address them promptly.
4. Document any regressions and the steps taken to resolve them for future reference.

Target failure type: regression_introduced
